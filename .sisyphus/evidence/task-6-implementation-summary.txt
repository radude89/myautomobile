## Architecture

### 7-Step Workflow

1. **Pre-flight Checks**
   - Validates: docker, docker compose, node (18+), playwright
   - Checks: config.json exists
   - Exits early if requirements missing

2. **Start YUZU**
   - Command: `docker compose up -d`
   - Health check: polls http://localhost:8080/health (max 30s)
   - Sets DOCKER_RUNNING flag for cleanup

3. **Extract Raw Screenshots**
   - Runs: `./extract-screenshots.sh --xcresult-path "$XCRESULT_PATH"`
   - Skippable: `--skip-extract` flag uses existing raw/ files
   - Validation: Checks raw/ has content before continuing

4. **Generate Framed Screenshots**
   - Runs: `node generate.mjs`
   - Uses: YUZU automation to apply design
   - Output: tools/screenshot-generator/fastlane/screenshots/{locale}/{size}/{id}.png

5. **Organize Output**
   - Reads: config.output.path from config.json
   - Transforms: {locale}/{size}/{id}.png → {locale}/{id}_{size}.png
   - Destination: PROJECT_ROOT/fastlane/screenshots/
   - Example: en/iPhone_6.9/vehicle-list.png → en/vehicle-list_iPhone_6.9.png

6. **Stop YUZU**
   - Command: `docker compose down`
   - Skippable: `--skip-cleanup` flag leaves container running
   - Cleanup trap: Runs automatically on EXIT/ERR

7. **Print Summary**
   - Reports: File count per locale
   - Shows: Total files generated
   - Displays: Elapsed time (minutes + seconds)

### CLI Flags

- `--skip-extract`: Use existing raw/ screenshots
- `--skip-cleanup`: Leave YUZU running for debugging
- `--xcresult-path <path>`: Pass to extraction script (required unless --skip-extract)
- `--help`: Show usage documentation

### Error Handling

**Trap handler**:
```bash
trap cleanup EXIT ERR
```

- Stops Docker on failure (unless --skip-cleanup)
- Preserves exit code
- Prints failure message with exit code

**Exit codes**:
- 0: Success
- 1: Any failure (missing tools, extraction failed, generation failed, etc.)

## Implementation Notes

### File Organization Algorithm

The organize_output() function implements a triple-nested loop:

```
for each locale in source_dir:
    for each size_folder in locale_dir:
        for each screenshot in size_folder:
            copy screenshot to dest_dir/{locale}/{screenshot-id}_{size-folder}.png
```

This transforms:
- tools/screenshot-generator/fastlane/screenshots/en/iPhone_6.9/vehicle-list.png
- → fastlane/screenshots/en/vehicle-list_iPhone_6.9.png

### Health Check Strategy

Polls YUZU health endpoint with 1-second intervals:
```bash
while [[ $attempt -lt 30 ]]; do
    if curl -sf http://localhost:8080/health > /dev/null 2>&1; then
        healthy=true
        break
    fi
    ((attempt++))
    sleep 1
done
```

Prevents premature automation attempts before YUZU is ready.

### Path Handling

Uses absolute paths throughout:
```bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(cd "$SCRIPT_DIR/../.." && pwd)"
```

Ensures pipeline works regardless of invocation location.

### JSON Parsing

Leverages Node.js (already required) to parse config.json:
```bash
local output_path=$(node -p "require('$CONFIG_FILE').output.path")
```

Avoids external dependency on jq.
